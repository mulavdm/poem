# POEM Knowledge Bundle

This is POEM's project-specific Open Knowledge Format bundle. It is documentation-as-code: when a feature, public API, protocol, or automation-surface change lands, the matching concept here should change in the same commit.

For the OKF format spec itself and shared cross-project engineering principles, see the single workspace-root reference checkout at `../../../OpenKnowledgeFormat/`. Do not edit that directory for POEM work.
